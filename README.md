# Audio Taskbar Indicator（音声インジケーター）

Windows 11 で、**音を出しているウィンドウのタスクバーボタンに目印を付ける**常駐ツールです。
「どこかから音が鳴っているけれど、どのウィンドウか分からない」を解消します。

## 機能

- **バッジ表示**：音を出しているウィンドウのタスクバーアイコン右下にバッジを付けます。色と形（スピーカー・丸・四角）を選べます。
- **オレンジ点灯**：Windows 標準の「注意を引く」点灯を流用し、タスクバーボタンをオレンジにします。
- **タイトル記号**：ウィンドウタイトルの先頭に `🔊` などの記号を付けます（初期設定はオフ）。
- **出力デバイスの選択**：仮想オーディオケーブルなど、実際には聞いていない出力先への音を判定から外せます。
- **アプリの除外**：常に音声セッションを持つアプリなどを判定から外せます。
- **ブラウザ・ストアアプリ対応**：別プロセスから音を出すアプリも、親プロセスをたどって本体のウィンドウに対応付けます。
- **管理者権限での常駐**：タスクスケジューラに登録し、ログオン時に UAC の確認なしで起動します。管理者権限で動くアプリのウィンドウにも表示できるようになります。

## 動作環境

- Windows 11
- Python 3.12（動作確認済み）

## インストール

```bat
git clone https://github.com/<your-name>/audio-taskbar-indicator.git
cd audio-taskbar-indicator
py -m pip install -r requirements.txt
```

起動するには `audio_taskbar_indicator.pyw` をダブルクリックします。タスクトレイにスピーカーのアイコンが表示されます。

> **複数の Python が入っている場合**
> ライブラリは、実際にツールを起動する Python に入れる必要があります。`py -0p` で一覧を確認し、`*` が付いているのが `py` やダブルクリックで使われる既定のバージョンです。特定のバージョンを使う場合は、インストールと起動の両方でバージョンを指定してください。
> ```bat
> py -3.12 -m pip install -r requirements.txt
> pyw -3.12 audio_taskbar_indicator.pyw
> ```

うまく起動しないときは、コンソール付きで起動するとエラーが表示されます。

```bat
py audio_taskbar_indicator.pyw
```

## 使い方

タスクトレイのアイコンを左クリック（または右クリック →「設定...」）すると、設定画面が開きます。右クリックメニューの「一時停止」で、すべての表示を一時的に消せます。

設定画面は次の4つのタブに分かれています。

| タブ | 内容 |
|---|---|
| 表示方法 | バッジ・オレンジ点灯・タイトル記号のオン・オフ、色、形 |
| 検出と出力デバイス | 判定する音量、表示を消すまでの秒数、確認間隔、除外するアプリ、監視する出力デバイス |
| 検出状況 | 音声セッションのあるアプリ・出力先・音量レベル・対応するウィンドウをリアルタイムで表示 |
| 権限と自動起動 | 管理者としての再起動、自動起動の登録・解除 |

表示がうまくいかないときは、まず「検出状況」タブを確認してください。黄色の行が「鳴っている」と判定されたものです。

## 管理者権限で動くアプリにも表示するには

Windows の仕組み上、通常の権限で動くツールからは、管理者権限で動くアプリのウィンドウを操作できません。

1. 設定画面の「権限と自動起動」タブで「管理者として再起動」を押し、UAC の確認を許可します。
2. 「ログオン時に管理者権限で自動起動する」を押します。

次回のログオンから、UAC の確認なしに管理者権限で常駐します。登録先はタスクスケジューラのタスク `AudioTaskbarIndicator` です。バッテリー駆動時も停止せず、実行時間の上限もない設定にしています。

> 自動起動には、登録した時点の Python とスクリプトの場所が記録されます。フォルダを移動したり Python を入れ替えたりしたら、登録し直してください。

## exe にする

`build_exe.bat` を実行すると、PyInstaller で `dist\AudioTaskbarIndicator.exe` を作ります。exe 版で自動起動を使う場合は、exe を起動してから設定画面で登録し直してください。

## 既知の制限

- **ブラウザ**：タブ単位では判定できません。音を出しているブラウザの全ウィンドウに目印が付きます。
- **バッジ**：本来は各アプリが自分のウィンドウに使う仕組み（`ITaskbarList3::SetOverlayIcon`）のため、アプリによっては反映されないことがあります。失敗した場合はログに記録されます。
- **オレンジ点灯**：そのウィンドウを前面にすると Windows が消します。背面に戻ったときにまだ鳴っていれば、再び点灯します。色は Windows の仕様でオレンジ固定です。
- **タイトル記号**：アプリがタイトルを書き換えるたびに付け直すので、一瞬ちらつくことがあります。
- **システム音**（通知音など）は対象外です。

## 設定ファイルとログ

`%APPDATA%\AudioTaskbarIndicator\` に保存されます（設定画面の「ログのフォルダを開く」から開けます）。

| ファイル | 内容 |
|---|---|
| `config.json` | 設定 |
| `log.txt` | 動作ログ |
| `icons\` | 生成したバッジアイコン |

アンインストールするときは、自動起動を解除してから、このフォルダとリポジトリのフォルダを削除してください。

## 仕組み

1. Windows Core Audio API（pycaw）で、全出力デバイスの音声セッションとピークレベルを取得します。
2. 表示中のトップレベルウィンドウを列挙し、プロセス ID で音声セッションと対応付けます。ウィンドウを持たないプロセスは、親プロセスをたどります。
3. 対応するウィンドウに対して、`ITaskbarList3::SetOverlayIcon`（バッジ）、`FlashWindowEx`（点灯）、`WM_SETTEXT`（タイトル）で目印を付けます。
